# news_reel

Прототип: ежедневный ролик из новостей дня. Шаг 1 из плана: монтаж карточек в вертикальное видео.

Сейчас работает:
- cards.py рисует карточки 1080x1920 из заголовков (свои карточки, без чужих фото);
- beat.py делает тестовый бит из кода, без авторских прав;
- telegram_source.py читает публичный Telegram-канал (t.me/s/канал) и собирает новости за день в JSON;
- build_video.py собирает ролик mp4 (h264 и aac) из карточек и звука.

Запуск:
    cd news_reel
    python3 telegram_source.py ostorozhno_novosti out/news.json 8   # новости за сегодня (по Москве)
    python3 build_video.py out/news.json out/reel.mp4

Тестовый вариант без интернета:
    python3 build_video.py sample_news.json out/reel.mp4

Нужны Python 3, Pillow и ffmpeg.

Секреты (токены, ключи) в репозиторий не кладутся: только в настройки окружения.
Правила владельца аккаунта: RULES.md.
Расчёты, КП и бот Smetana этим кодом не затрагиваются.

Важно: тексты канала принадлежат его авторам, использование на свой риск. Публикация в Instagram пока не включена.

## Видео с персонажем (fal.ai)
fal_video.py: персонаж читает трек (картинка + вокал, модель bytedance/omnihuman/v2, 0,105 доллара за секунду).
Нужен пакет fal-client (pip install fal-client) и ключ FAL_KEY в окружении (не в репозитории).
Без флага --go скрипт только считает стоимость.
