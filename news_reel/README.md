# news_reel

Прототип: ежедневный ролик из новостей дня. Шаг 1 из плана: монтаж карточек в вертикальное видео.

Сейчас работает:
- cards.py рисует карточки 1080x1920 из заголовков (свои карточки, без чужих фото);
- beat.py делает тестовый бит из кода, без авторских прав;
- build_video.py собирает ролик mp4 (h264 и aac) из карточек и звука.

Запуск:
    cd news_reel
    python3 build_video.py sample_news.json out/reel.mp4

Нужны Python 3, Pillow и ffmpeg.

Секреты (токены, ключи) в репозиторий не кладутся: только в настройки окружения.
Расчёты, КП и бот Smetana этим кодом не затрагиваются.
